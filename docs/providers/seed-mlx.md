# Seed-Coder on Reticle MLX

Seed-Coder remains Reticle MLX's recommended quality preset, but the service and
native menu-bar app now support multiple MLX-LM models.

See the current [Reticle MLX guide](mlx.md) for installation, model selection,
performance, migration from `reticle-seed-mlx`, monitoring, and uninstall.
